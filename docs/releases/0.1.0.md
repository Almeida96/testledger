TestLedger imports JUnit XML and gives an AI agent a structured way to investigate
test failures through MCP. The implementation is Kotlin on Java 21 with SQLite.

- Six read-only tools for run summaries, failure groups, comparisons, history,
  and source evidence.
- A reusable triage-tests MCP prompt with a concrete investigation sequence.
- Separate categories for regressions, persistent failures, recoveries, skipped
  tests, and tests that disappeared from a run.
- Immutable imports, retry hints, bounded XML parsing, and credential-pattern
  redaction before persistence.
- A four-run demo with a real Kotlin-server/TypeScript-client MCP connection.

Download `testledger-0.1.0.zip`, extract it, and run `bin/testledger --help`
(`bin/testledger.bat` on Windows). Requires Java 21 or later.

The release workflow runs the JVM and protocol suites on Linux and Windows,
then publishes the tested Linux-built distribution. SHA-256 checksums are included.

No model API key is required by TestLedger. The agent runs in your MCP client.
Failure grouping and intermittent outcomes are diagnostic hints, not proof of
root cause or flakiness. No live-model diagnosis is claimed by this release.
